# Ghost Brain starter

Use a full clone and the shared installer:

```bash
bash starter/install.sh
```

This is the same native-first install as `bash install.sh`, not a separate product or remote pipe-to-shell installer. It requires an existing workspace and preserves existing instructions. See the [main README](../README.md) for installed files, compatibility options and isolated tests, then follow [BOOTSTRAP.md](BOOTSTRAP.md).

Other persona templates in this directory are optional examples; the default installer does not copy them. No runtime, vault sync or schedules are configured.
