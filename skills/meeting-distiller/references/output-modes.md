# Output Modes

Pick the smallest useful format.

## 1. Quick Summary

Use when the user just wants the gist.

Structure:
- 2-5 bullet summary
- 1 line on next step

## 2. Full Distillation

Default for important meetings.

Structure:
- Summary
- Confirmed facts
- Decisions
- Action items
- Open questions / risks
- Recommended next move

## 3. Action Extraction

Use when the user mainly wants execution.

Structure:
- Action items table/bullets
- Missing owners / due dates
- Immediate next action for the user

## 4. Decision Log

Use when the main value is what got agreed.

Structure:
- Decision
- Why it matters
- Confidence / source basis
- What remains unresolved

## 5. Team Update

Use when the user wants something ready to paste internally.

Structure:
- Short context line
- What was covered
- What was decided
- What happens next

Tone: concise, practical, not overly formal.

## 6. Client-Safe Recap

Use when the message may be forwarded externally.

Structure:
- Meeting purpose
- What was reviewed
- Agreed next steps
- Any required customer input

Tone: cleaner, neutral, avoid internal shorthand and uncertainty unless necessary.

## Heuristic

If not specified:
- small routine meeting → Quick Summary
- working session with demos/tasks → Full Distillation
- “what do we need to do?” → Action Extraction
- “make this ready to send” → Team Update or Client-Safe Recap
