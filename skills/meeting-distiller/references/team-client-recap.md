# Team / Client Recap

Convert a meeting distillation into a message someone can actually send.

## Internal team recap

Use this style:

- what the meeting was about
- what was shown or clarified
- what was decided
- what the next actions are
- what input is still needed

Tone:
- direct
- practical
- slightly informal is okay
- avoid unnecessary ceremony

## Client-safe recap

Use this style:

- thank-you / context line if appropriate
- short summary of what was reviewed
- agreed next steps
- required input from client
- optional note on next check-in

Tone:
- clean
- neutral
- professional
- no internal blame, uncertainty dumps, or speaker-label jargon

## Compression rule

If the user wants a paste-ready message, keep it short enough to send without editing.

## Example internal framing

"สรุปจาก session เมื่อเช้า: วันนี้ทีม walkthrough วิธีเข้าหลังบ้านและวิธีแก้ Quiz ให้คุณแพรแล้ว ประเด็นค้างหลักคือรออีเมลเพื่อสร้าง user และเปิดสิทธิ์เข้าระบบ..."

## Example client-safe framing

"จากการประชุมวันนี้ เราได้ทบทวนวิธีเข้าระบบหลังบ้านและวิธีแก้ไขข้อสอบในส่วน Quiz แล้ว ขั้นตอนถัดไปคือขออีเมลสำหรับสร้างผู้ใช้งานและเปิดสิทธิ์เข้าถึงระบบ..."
