# Final Review / Publish Checklist Pack

Use this before any action that is hard to undo, costly, externally visible, or time-sensitive.

## When to use it
- before publish
- before submit/save on important records
- before deleting or pausing live items
- before sending messages/emails/forms externally
- before any spend-impacting change

## Checklist
1. **State check**
   - confirm you are on the intended page/tab/item
   - confirm the correct account, record, campaign, or environment
2. **Artifact check**
   - confirm the visible values/assets match the intended ones
   - verify URLs, media, text, counts, dates, identities, or recipients
3. **Risk check**
   - identify what could go wrong if clicked now
   - call out irreversible or expensive consequences
4. **User-approval check**
   - if the action has external impact, summarize and request/confirm approval
5. **Execution check**
   - click only after the above is satisfied
6. **Post-action check**
   - verify the UI confirms the action actually succeeded
   - re-snapshot after the transition

## Compact report format
- **Ready?** yes / no
- **Checked:** key items verified
- **Risk:** what could still go wrong
- **Action:** what clicking next will do
