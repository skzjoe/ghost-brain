# Dropdowns and Comboboxes

Use this when fields behave like searchable pickers instead of plain selects.

## Procedure
1. Click the combobox ref.
2. Snapshot again if the option list opens.
3. Type to filter when allowed.
4. Select the exact option by ref.
5. Re-snapshot to confirm the value stuck.

## Recovery
- If options do not appear, press Enter or ArrowDown, then re-snapshot.
- If the list is virtualized, scroll the list container only after confirming it exists.
