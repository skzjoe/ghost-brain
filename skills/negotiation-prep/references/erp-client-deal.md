# ERP / Client Deal Negotiation

Use when the user is preparing for ERP implementation deals, software/service proposals, commercial scope discussions, or client expectation alignment.

## Issues to map beyond price

- project scope boundary
- customization ceiling
- milestones / payment terms
- implementation timeline
- sign-off / UAT conditions
- support period
- response SLA
- training hours
- change request process
- deployment / handover conditions
- client-side dependencies

## Key questions

- What is the client actually buying: software, delivery confidence, speed, lower risk, or team support?
- Which scope items are truly must-have and which are negotiable?
- What can be converted into phased delivery instead of upfront commitment?
- What must be tied to change requests to avoid scope creep?

## Good trade examples

- lower price ↔ narrower scope
- faster timeline ↔ stronger client-side dependency commitments
- extra support ↔ higher fee or reduced custom work
- phased delivery ↔ milestone-based payment clarity

## Watchouts

- vague scope
- hidden expectations not written into the deal
- “quick tweak” requests that are really custom work
- agreeing support intensity without SLA boundaries
