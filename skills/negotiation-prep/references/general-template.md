# General Negotiation Prep Template

Use for any important negotiation when no domain-specific template is more suitable.

## Core sections

- Deal context
- Real objective
- BATNA / alternatives
- Other side's likely interests
- Negotiable issues map
- Concession plan
- Package design
- Opening strategy
- Close / commitment checklist

## Core reminders

- Do not negotiate only one variable if more issues can be introduced.
- Treat every concession as an exchange.
- Clarify must-have vs nice-to-have.
- Check whether the final deal is better than the BATNA.

## Recommended artifact

Point the user to a Markdown prep sheet that can be reused or filled for a live case.
