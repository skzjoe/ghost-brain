# Live Case Mode

Use this when the user provides a real negotiation context and wants a first-pass filled draft instead of a blank template.

## Goal

Turn incomplete real-world context into a usable negotiation prep draft.

## Operating rules

- Fill what can be inferred confidently.
- Mark uncertain fields as **Assumption** or **To confirm**.
- Do not fabricate facts.
- Prefer a useful draft over asking too many questions up front.
- Ask only for the minimum missing information needed to avoid a weak or misleading draft.

## Minimum inputs for a live-case draft

Try to identify at least:
- negotiation type
- counterparty
- desired outcome
- key constraint or tension

Useful extras:
- timing/deadline
- current offer or dispute point
- known alternatives
- known pain points on both sides

## Drafting pattern

1. Identify the negotiation type
2. Fill the standard prep sections with what is known
3. Mark unknowns explicitly
4. Add a short section called **Open questions to confirm**
5. Add a short section called **Recommended opening approach**

## Output rule

For live-case drafts, produce something the user can review and edit quickly rather than a generic lecture.
