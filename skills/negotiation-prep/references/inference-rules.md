# Inference Rules

Use these rules when creating a filled draft from partial context.

## Safe to infer

You may infer high-level structure such as:
- likely negotiation category
- likely decision pressure
- likely issues worth mapping
- probable must-have vs nice-to-have candidates

## Do not infer as fact

Do not state as confirmed unless provided:
- exact budget or price limit
- exact BATNA quality
- exact counterparty priorities
- legal/commercial commitments
- role/title/comp package details

## Labeling rules

Use these labels clearly:
- **Confirmed** — explicitly provided by the user
- **Assumption** — reasonable working assumption
- **To confirm** — important but unknown

## Preferred behavior

If partial context is enough for a useful draft, proceed.
If the missing information would distort the strategy, ask targeted follow-up questions.
