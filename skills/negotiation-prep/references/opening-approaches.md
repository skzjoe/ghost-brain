# Opening Approaches

Use this reference to draft a practical opening move for the negotiation.

## Goals of a good opening

- set the tone
- frame the shared objective
- surface priorities before exchanging concessions
- avoid revealing the floor too early

## Generic opening structure

1. Frame the shared goal
2. Confirm context and constraints
3. Ask one or two priority questions
4. Transition into options/packages

## Example patterns

### Collaborative commercial opening
"อยากให้รอบนี้คุยกันให้ชัดทั้งเรื่อง scope, timeline และ commercial เพื่อให้จบแบบที่ทั้งสองฝั่งทำงานต่อได้จริง"

### Vendor alignment opening
"เป้าคือหาจุดที่ทั้งเรื่องราคา คุณภาพ และ timeline ไปด้วยกันได้ ไม่อยาก fix แค่เลขอย่างเดียวแล้วปลายทางมี rework"

### Hiring/comp opening
"อยากคุยให้ชัดทั้งเรื่อง package, role expectation และสิ่งที่จะทำให้ดีลนี้ work สำหรับทั้งสองฝั่งในระยะยาว"

## Rule

Keep the opening calm, practical, and issue-broadening.
